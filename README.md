ERC-20 Token on Sepolia Testnet

Overview
This project demonstrates the creation and deployment of a custom ERC-20 token using Solidity and OpenZeppelin.  
The token is deployed on the Sepolia Ethereum Testnet for learning and testing purposes.

Tech Stack
- Solidity **>=0.8.2 <0.9.0**
- OpenZeppelin ERC-20
- Remix IDE
- MetaMask
- Sepolia Testnet

Token Details
- Name: AMEYA Token
- Symbol: AME
- Total Supply: 50,000,000 AME 
- Network: Sepolia Testnet

Smart Contract
The contract extends OpenZeppelin's ERC20 implementation and mints an initial supply to the deployer.

Deployment
- Network: Sepolia
- Deployed using Remix + MetaMask
